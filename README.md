# MY NINE LOVES

好きなCD・漫画・書籍・アニメ・映画・有名人・キャラクターを9つ選ぶと、
1枚のカード画像になるツール。登録不要・無料。

本番: https://mynineloves.com

---

## 動かす

Node 22以上が必要です（`node:sqlite` と最新の `fetch` を使うため）。

```
cd nine-server
npm install
node server.js
```

**`npm install` は必須です。** OGP画像の生成に `@napi-rs/canvas`、
PostgreSQL接続に `pg` を使っています。
Renderの **Build Command にも `npm install`** を設定してください。

---

## 構成

```
server.js          ルーティング / キャッシュ / レート制限 / 画像プロキシ
                   / 共有ページのHTML生成 / GA・LinkSwitchの注入
providers.js       外部APIのアダプタ（検索・関連作品・購入リンク）
db.js              保存と集計（PostgreSQL / SQLite / JSON の3段フォールバック）
ads.js             広告の出し分け
ogimage.js         共有ページのサムネイル画像を生成
fonts/             日本語フォント2種（同梱の理由は後述）
public/            画面。index / trends / about / terms / privacy / contact
data/              ローカルの保存データ（自動生成。Gitに入れない）
```

## ページ

| URL | 内容 |
|---|---|
| `/` | エディタ本体 |
| `/trends` | みんなの9つ・ランキング |
| `/u/ユーザー名` | その人が作ったカード一覧 |
| `/c/:id` | **共有ページ**。`server.js` がHTMLを組み立てる |
| `/about` `/terms` `/privacy-policy` `/contact` | 説明・規約類 |

`/c/:id` だけ静的ファイルではなくサーバー生成なのは、
**SNSのクローラーがJavaScriptを実行しない**ためです。
OGPタグと中身をHTMLの時点で埋め込む必要があります。

## OGP画像

`/og/:id.png` で 1200×630 の画像を生成します。
SNSにURLを貼ったときのサムネイルです。

**レイアウトは上4＋下5。** 3×3にすると縦長の表紙が小さくなるためです。
2段5列なら高さに余裕ができ、本来の縦横比のまま大きく見せられます。
CDのように正方形の絵柄のときだけ、文字を上に置いてグリッドを横幅いっぱいに広げます。

**`fonts/` を消さないでください。** Renderの実行環境には日本語フォントが無く、
同梱しないと文字がすべて豆腐（□□□）になります。

見え方の確認は `https://www.opengraph.xyz/` に共有URLを貼るのが手軽です。
X・Facebook・LINEでの表示を一度に見られます。
**一度取得されるとSNS側にキャッシュされる**ので、調整は数回で済ませてください。

## 広告

環境変数が2つあります。役割が違います。

| | 用途 | キーの形 |
|---|---|---|
| `ADSENSE_JSON` | アドセンス。**全ページ共通** | 置き場所だけ |
| `ADS_JSON` | アフィリエイト。**ページごと** | `{ページ}_{場所}_{言語}` |

置き場所は5つ。

| キー | どこ | 想定 |
|---|---|---|
| `rail` / `rail2` | PC画面の右／左 | アドセンス |
| `bar` | 下部の固定バー | アドセンス |
| `inflow` / `inflow2` | 本文内 300×250 を2つ | アフィリエイト |

**左右と下部はアドセンス優先**、無ければアフィリエイトで埋めます。
**本文内はその逆**でアフィリエイト優先。
これにより、アドセンス通過前後で `ADS_JSON` を書き換える必要がありません。

値を配列にすると、その中からランダムで1つ選ばれます（半々表示）。

書き方の詳細は `ADS-SETUP.md` を参照してください。
A8のHTMLを貼るときは、**改行を削除して `"` を `'` に置換**します。

## 注意点

### CDの内部名は `album`

画面では「CD」ですが、コードの中では `album` です。
`providers.js` の購入リンク判定表に `cd` しか書いていなかったために、
**CDだけアフィリンクが出ない**不具合が実際に起きました。
種別を扱う箇所を触るときは両方を確認してください。

### 楽天が見ているのは Referer ではなく Origin

403で `REQUEST_CONTEXT_BODY_HTTP_REFERRER_MISSING` が返ることがあります。
文面はRefererですが、**実際に必要なのは `Origin` ヘッダー**です。
現在は Origin と Referer の両方を、値の形を変えながら順に送っています。

`RAKUTEN_REFERER` は複数書いても構いません。
スペースや改行で区切られていれば、上から順に試します。

通らない場合は、楽天ウェブサービスの **Allowed websites** に
ドメインが登録されているか（1行に1ドメイン）と、
保存から5〜10分の反映待ちを確認してください。

### CDの検索は2段構え

アルバム検索で6件未満のときは、曲名でも検索してアルバムに読み替えます。
サウンドトラックや、アルバム名と曲名が違うものを拾うためです。

### 画像は保存せずURLだけを持つ

保存すると複製・再配布にあたり、多くのAPIの規約に触れます。
`card_items.image_url` にはURL文字列だけを記録しています。

利用者がアップロードした画像は端末内でのみ処理し、
サーバーには送りません。したがって共有ページにも出ません。

### ローカルで `table cards has no column` が出たら

古い `data/nine.db` が残っています。`data` フォルダを消せば直ります。

## 保存と集計

書き出し・共有のときに `POST /x/cards` で1件記録します。

テーブルは4つです。

| | |
|---|---|
| `cards` | カード本体 |
| `card_items` | 9つの中身 |
| `item_stats` | ランキング用の集計 |
| `kv` | 外部APIの応答キャッシュ |

**ランキングは `card_items` から直接集計していません。寿命が違うためです。**
カードは90日で消えますが、ランキングは積み上げを残したい。
`item_stats` は保存時に `(種類, 提供元, 作品ID, 言語, 生まれた年代)` ごとに
1ずつ加算し、`store.top()` はこちらを読みます。カードが消えても数字は残ります。

起動時に `item_stats` が空で `card_items` に行があれば、既存のカードから
自動で積み直します。この版に上げても過去のランキングは失われません。

- 年齢は**生まれ年に変換**して保存（毎年の一斉更新を不要にするため）
- 言語も保存し、ランキングを言語別に出せる
- 閲覧もいいねも0のまま90日経ったものは自動削除（集計は残る）

**公開前に `IP_SALT` を必ず設定してください。**
`.gitignore` に `data/` が入っていることも確認してください。

## 負荷への備え

同種のサービス（my9games.com）が公開7日でアクセス集中により停止した事例があり、
その振り返り記事を踏まえて次の手を入れてあります。

| 弱点 | 対策 | 場所 |
|---|---|---|
| 再起動でキャッシュが消える | 検索結果をDBの `kv` にも置く2段構え | `cacheGet2` / `cacheSet2` |
| 表記ゆれで同じ検索を何度も叩く | キャッシュキーを正規化 | `P.cacheKey` |
| 期限切れの瞬間に行列ができる | 古い内容を返し、裏で更新 | `refreshLater` |
| **同じ語を同時に検索すると人数分叩く** | 取得を1本にまとめる（30回→1回） | `once` |
| 同じ画像を同時に要求すると人数分取得 | 同上（20回→1回） | `fetchImageOnce` |
| 同じOGP画像を同時に生成する | 同上（15回→1回）。CPUを最も食う箇所 | `once('ogrender:')` |
| 作成数・一覧が毎回DBに問い合わせ | 30秒だけ持つ | `cacheGet('stats')` / `listKey` |
| 共有ページが毎回DBに問い合わせ | 5分持つ | `cacheGet('card:')` |
| 静的ファイルを毎回読み直す | 組み立て済みを保持 | `staticCache` |
| 1表示ごとに閲覧数をUPDATE | 3分ぶんをまとめて1回 | `countView` / `flushViews` |
| 画像でメモリを使い切る | 画像だけ別枠にし、合計バイト数で制限 | `imgCacheSet`（既定64MB） |
| ランキングがカードと一緒に消える | 集計を `item_stats` に分離 | `db.js` |
| 同一IPの人がまとめて弾かれる | 全体は緩く、外部APIを叩く分だけ別枠で制限 | `rateLimited` |
| 画像配信が本体を圧迫する | 前段にCloudflareを置く | `CLOUDFLARE.md` |
| 監視だけで帯域を月676MB使う | 監視先を `/healthz`（2バイト）に | `CLOUDFLARE.md` |

日本のスマホ回線は多数の利用者が同じIPを共有します（CGNAT）。
IPだけで厳しく数えると、拡散したときに無関係の人まで429になります。
キャッシュに当たったリクエストは外部APIを叩かないので、数えていません。

**拡散させる前に `CLOUDFLARE.md` を実施してください。** DNSを変えるだけで、
画像のトラフィックがほぼサーバーに届かなくなります。

**Renderは無料アカウントでも帯域超過を課金します**（$0.15/GB、無料枠は月5GB）。
監視先をトップページ（82KB）のままにすると、それだけで月676MB＝枠の13%を使います。
UptimeRobotの宛先を `/healthz` に変えてください。
